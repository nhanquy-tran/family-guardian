# 0001. Record decisions as ADRs

Date: 2026-11-17. Status: accepted.

## Decision
Every significant decision gets a short Architecture Decision Record in `docs/decisions/`, numbered, with context, decision and consequences. Agents read them before designing changes and propose a new ADR when a change contradicts one.

## Consequences
Decisions are versioned plain files (Zühlke AI Factory rule 4) and traceable in Git history.
