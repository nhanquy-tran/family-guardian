# 0009. Windows first, distributed via the Chrome Web Store

Date: 2026-11-17. Status: accepted.

## Decision
MVP supports Windows with Chrome, Edge and Brave. The extension is published as an unlisted item on the Chrome Web Store. Edge and Brave install it from the same store via policy.

## Risks
Store review can take days. Mitigation: submit the skeleton on day 2 with a clear privacy policy; develop and test with the unpacked build meanwhile.
