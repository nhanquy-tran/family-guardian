# Family Guardian

Simple parental monitoring for kids' Windows laptops: a Chrome/Edge/Brave extension plus a web dashboard.

- See which sites your child uses and for how long
- Block sites
- Daily focus score (homework vs. distraction)
- Alert when the extension is removed or goes silent

Built by one human and an AI factory (Claude Code + OpenSpec + GitHub Actions). See `docs/` for architecture, decisions and roadmap.

Status: MVP in progress.
